# Painel Administrativo Rastro e Voz · Pacote para desenvolvimento (versão 2)

## O que mudou nesta versão
- O painel abre sempre no **tema claro**. Antes ele seguia o modo escuro do computador e ficava todo verde escuro.
- O arquivo **funciona sem internet**: as bibliotecas estão embutidas.

## Como usar
1. Abra `prototipo/painel-rastro-e-voz.html` com duplo clique, no Google Chrome ou Microsoft Edge.
   Versão online: https://claude.ai/artifact/NRXcWaWNGeSRQoyn3L3XkQ
2. Leia `docs/HANDOFF-DEV.md`: rotas, design tokens, componentes, eventos obrigatórios, modelo de dados, SQL dos indicadores, endpoints e critérios de aceite.
3. `docs/documentacao-funcional.md` descreve o comportamento de cada tela.

A barra lateral verde escura é a cor da marca. O restante da tela deve aparecer claro, com fundo `#F3F6F1` e cartões brancos.
Se aparecer escuro, abra o menu "Marcos" no rodapé da barra lateral e escolha "Usar tema claro".

Os dados do protótipo são fictícios. Comece pela seção 4 do handoff (registro de eventos).
